# Установка vpn.io

vpn.io распространяется не через App Store / Microsoft Store, поэтому при **первом**
запуске система покажет предупреждение, что приложение не подписано Apple/Microsoft.
Это нормально и безопасно. Ниже — как установить и открыть. Делается один раз.

## macOS

1. Нажмите на файл **`vpn.io.pkg`** **правой кнопкой мыши** и выберите **Открыть**
   (так как приложение не подписано Apple). В появившемся окне нажмите **Открыть**
   ещё раз.
2. Пройдите установщик кнопкой **Продолжить** и введите пароль администратора,
   когда попросит — он ставит фоновую службу.
3. После установки откройте **vpn.io** из папки **Программы**.

Установщик кладёт приложение и фоновую службу, которая запускается сама. Дальше
vpn.io открывается обычным двойным кликом.

Удалить можно одной командой (спросит пароль), затем перетащить приложение в Корзину:

```
sudo /Applications/vpn.io.app/Contents/Resources/uninstall.sh
```

Скрипт останавливает root-демон и удаляет хелпер, сокет (0666), лог, конфиг ротации и receipt пакета — иначе они остаются работать после удаления приложения. В конце перетащите `vpn.io.app` в Корзину.

## Linux (Debian / Ubuntu)

1. Установите скачанный пакет (имя файла зависит от версии):

   ```
   sudo apt install ./vpn-io_*.deb
   ```

2. **Выйдите из системы и войдите снова** один раз — чтобы ваш аккаунт попал в
   группу `vpn-io` (она даёт приложению доступ к фоновой службе).
3. Запустите **vpn.io** из меню приложений.

## Windows

1. Запустите **`vpn-io-setup.exe`**.
2. Появится синее окно **«Система Windows защитила ваш компьютер»** (SmartScreen,
   потому что приложение не подписано). Нажмите **«Подробнее»**, затем
   **«Выполнить в любом случае»**.
3. Подтвердите запрос **«Разрешить этому приложению вносить изменения?»** —
   нажмите **Да** (установщик регистрирует фоновую службу).
4. Пройдите мастер установки кнопкой **Next** и в конце — **Finish**.

Установщик кладёт приложение, фоновую службу и сетевой драйвер, после чего служба
запускается сама. Запускайте **vpn.io** ярлыком с рабочего стола или из меню Пуск.

Чтобы удалить — «Параметры → Приложения → vpn.io → Удалить» (служба снимется
автоматически).

---

После установки нажмите кнопку импорта и укажите файлы вашего профиля
(сертификаты и адрес сервера) — их вам выдаёт администратор.
