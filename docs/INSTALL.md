# Установка vpn.io

vpn.io распространяется не через App Store / Microsoft Store, поэтому при **первом**
запуске система покажет предупреждение, что приложение не подписано Apple/Microsoft.
Это нормально и безопасно. Ниже — как установить и открыть. Делается один раз.

## macOS

1. Откройте файл **`vpn.io.dmg`**.
2. Перетащите значок **vpn.io** в папку **Applications** (Программы).
3. Откройте **Программы**, нажмите на **vpn.io** **правой кнопкой мыши** и выберите
   **Открыть**.
4. Появится предупреждение — нажмите **Открыть** ещё раз.

Дальше приложение будет открываться обычным двойным кликом. Если случайно
кликнуть дважды и macOS напишет «не удаётся открыть» — просто закройте это окно и
повторите через **правый клик → Открыть**.

## Linux (Debian / Ubuntu)

1. Установите скачанный пакет (имя файла зависит от версии):

   ```
   sudo apt install ./vpn-io_*.deb
   ```

2. **Выйдите из системы и войдите снова** один раз — чтобы ваш аккаунт попал в
   группу `vpn-io` (она даёт приложению доступ к фоновой службе).
3. Запустите **vpn.io** из меню приложений.

## Windows

Скоро.
